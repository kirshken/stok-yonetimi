# Stok Yönetimi
Yerel stok/barkod/SKT uygulaması. İndir, zip'i aç, çift tıkla; tarayıcıda açılır.
Veriler: kullanıcı klasörü altında `StokYonetimi-Veri` (otomatik yedekli).
Mac: ilk açılışta uyarı çıkarsa sağ tık → Aç. Windows: "Yine de çalıştır".

## Telefon / ağ modu
Ayarlar → Telefon / ağ modu: PIN belirle, aç. Telefon aynı Wi-Fi/hotspot'ta `https://<bilgisayar-ip>:<port>` adresini açar (QR ekranda).
İlk açılışta sertifika uyarısı normaldir (Gelişmiş → Devam). Kamera için HTTPS gerekir.
